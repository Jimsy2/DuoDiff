# DuoDiff 0.7 ##
A single-file HTML page for comparing two text files side-by-side with visual difference highlighting.

## Features ##
 - **Side-by-side comparison** — You have to press a button to see differences highlighted
 - **Character-level diff highlighting** — Precisely pinpoint what changed
 - **Line numbering** — Toggle line numbers on/off for reference
 - **Difference counter** — Shows total highlights and line count differences
 - **Two editable text panels** — allows synchronizing the comparison by adding lines
 - **Local & safe** — Runs entirely in your browser, no data sent anywhere
 - **One-click save** — Save the current state as an HTML file (Ctrl+S)
 - **Dark theme** — Easy on the eyes at night
 - **Drag 'n Drop** file upload support

## Quick Start

👉 **[Open DuoDiff Live](https://jimsy2.github.io/DuoDiff/)**

No installation needed. Just open the link and start comparing!

## How to Use

1. **Paste or edit text** in the left and right panels
2. **Click "Highlight differences"** to see what changed
3. **Toggle "Line numbers"** if you need line references
4. **Save your work** with Ctrl+S or the Save button

## Keyboard Shortcuts

- **Ctrl+S** (or Cmd+S on Mac) — Save current state as HTML file

## Use Cases

- Compare different versions of code
- Spot changes in configuration files
- Review document revisions
- Analyze text modifications
- QA testing
